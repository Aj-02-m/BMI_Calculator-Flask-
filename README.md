📊 BMI Calculator Web App

A simple and user-friendly BMI (Body Mass Index) Calculator built using Flask, HTML, and CSS.
This web application allows users to enter their weight and height, calculates their BMI, and displays the result on the same page along with a personalized health message based on the BMI category.

🚀 Features

User input for weight and height

Instant BMI calculation

Result displayed on the same page (no page reload)

Personalized message based on BMI value:

Underweight

Normal weight

Overweight

Obese

Clean and responsive UI using HTML & CSS

Backend logic handled with Flask

🛠️ Tech Stack

Backend: Flask (Python)

Frontend: HTML, CSS

Template Engine: Jinja2

📌 How It Works

User enters height and weight

Flask processes the input

BMI is calculated using the standard formula

BMI value and a health-related message are rendered on the same page

💡 Use Case

This project is ideal for:

Beginners learning Flask

Understanding form handling in web apps

Practicing frontend-backend integration

Building simple health-related web tools
